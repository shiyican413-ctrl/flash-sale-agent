# 开发计划

## 阶段 1：项目初始化

目标：搭建基础工程。

任务：

- 创建 Spring Boot 3 项目
- 引入 Web、Validation、Security、MyBatis-Plus、MySQL、Redis、MQ、Swagger
- 配置统一响应格式
- 配置全局异常处理
- 配置日志
- 配置 Docker Compose

交付物：

- 项目可启动
- Swagger 可访问
- MySQL、Redis、MQ 可连接

## 阶段 2：用户与权限

目标：完成基础登录鉴权。

任务：

- 用户注册
- 用户登录
- 密码加密
- JWT 生成和校验
- 管理员角色
- 接口权限拦截

交付物：

- 普通用户可登录
- 管理员接口需要管理员权限

## 阶段 3：商品与活动管理

目标：完成秒杀基础业务配置。

任务：

- 商品 CRUD
- 活动 CRUD
- 秒杀库存配置
- 活动状态流转
- 活动列表和详情查询

交付物：

- 管理员可创建活动
- 用户可查看活动

## 阶段 4：缓存预热

目标：把秒杀热点数据放入 Redis。

任务：

- 活动详情写入 Redis
- 活动库存写入 Redis
- 设置缓存过期时间
- 预热接口
- 缓存一致性校验

交付物：

- 活动上线前可一键预热

## 阶段 5：秒杀核心链路

目标：完成高并发抢购主链路。

任务：

- 动态秒杀地址
- 验证码
- Redis Lua 扣库存
- 用户重复购买校验
- MQ 发送下单消息
- 秒杀结果查询

交付物：

- 用户可以抢购
- 库存不会超卖
- 重复抢购会被拦截

## 阶段 6：异步订单

目标：完成订单异步创建。

任务：

- MQ 消费者
- 订单创建
- 消息幂等
- 数据库唯一索引兜底
- 订单状态管理

交付物：

- 秒杀成功后可生成订单

## 阶段 7：支付与超时关闭

目标：完善订单闭环。

任务：

- 模拟支付
- 支付成功状态变更
- 延迟队列关闭超时订单
- 库存回补
- 库存流水

交付物：

- 未支付订单可自动关闭
- 库存可回补

## 阶段 8：限流与风控

目标：提升系统抗压能力。

任务：

- 用户级限流
- IP 级限流
- 接口限流
- 黑名单
- 请求签名
- 重复提交 Token

交付物：

- 高频恶意请求会被拦截

## 阶段 9：Agent 模块

目标：增加 AI Agent 加分能力。

任务：

- Agent 任务表
- 活动巡检 Agent
- 库存风险分析 Agent
- 异常订单分析 Agent
- 压测报告总结 Agent
- Agent 任务查询接口

交付物：

- 管理员可以发起 Agent 分析任务
- 系统能输出自然语言分析结果

## 阶段 10：测试与压测

目标：准备面试展示材料。

任务：

- 单元测试
- 接口测试
- JMeter 或 k6 压测脚本
- README
- 架构图
- 面试讲解稿

交付物：

- 可运行项目
- 可展示压测结果
- 可讲清楚架构设计

## 建议开发顺序

1. 先做普通 CRUD 和登录，不要一开始就写高并发逻辑。
2. 再做 Redis 预热和 Lua 扣库存。
3. 然后接 MQ 异步下单。
4. 最后补限流、风控、Agent 和压测。

# 接口设计

## 通用响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

## 通用错误码

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数错误 |
| 40100 | 未登录 |
| 40300 | 无权限 |
| 40901 | 重复请求 |
| 42900 | 请求过于频繁 |
| 50000 | 系统异常 |
| 60001 | 活动不存在 |
| 60002 | 活动未开始 |
| 60003 | 活动已结束 |
| 60004 | 库存不足 |
| 60005 | 已经抢购过 |
| 60006 | 验证码错误 |

## 用户认证

### 注册

`POST /api/auth/register`

请求：

```json
{
  "username": "zhangsan",
  "password": "123456",
  "phone": "13800000000"
}
```

### 登录

`POST /api/auth/login`

请求：

```json
{
  "username": "zhangsan",
  "password": "123456"
}
```

响应：

```json
{
  "token": "jwt-token",
  "expiresIn": 7200
}
```

## 秒杀活动

### 活动列表

`GET /api/seckill/activities`

查询参数：

- `status`
- `page`
- `size`

### 活动详情

`GET /api/seckill/activities/{activityId}`

响应：

```json
{
  "activityId": 10001,
  "activityName": "iPhone 秒杀",
  "goodsId": 20001,
  "goodsName": "iPhone",
  "seckillPrice": 3999.00,
  "startTime": "2026-06-01 10:00:00",
  "endTime": "2026-06-01 10:10:00",
  "stockVisible": true,
  "stock": 100
}
```

### 获取验证码

`GET /api/seckill/activities/{activityId}/captcha`

响应：

```json
{
  "captchaId": "uuid",
  "imageBase64": "base64-image"
}
```

### 获取动态秒杀地址

`POST /api/seckill/activities/{activityId}/path`

请求：

```json
{
  "captchaId": "uuid",
  "captchaCode": "7x9k"
}
```

响应：

```json
{
  "path": "a8f3c7e2b1"
}
```

### 发起秒杀

`POST /api/seckill/activities/{activityId}/purchase/{path}`

请求：

```json
{
  "quantity": 1
}
```

响应：

```json
{
  "requestId": "uuid",
  "status": "PROCESSING"
}
```

### 查询秒杀结果

`GET /api/seckill/result/{requestId}`

响应：

```json
{
  "requestId": "uuid",
  "status": "SUCCESS",
  "orderNo": "SO202605290001"
}
```

状态：

- `PROCESSING`
- `SUCCESS`
- `FAILED`

## 订单

### 订单列表

`GET /api/orders`

### 订单详情

`GET /api/orders/{orderNo}`

### 模拟支付

`POST /api/orders/{orderNo}/pay`

### 取消订单

`POST /api/orders/{orderNo}/cancel`

## 管理端

### 创建商品

`POST /api/admin/goods`

### 创建秒杀活动

`POST /api/admin/seckill/activities`

请求：

```json
{
  "goodsId": 20001,
  "activityName": "iPhone 秒杀",
  "seckillPrice": 3999.00,
  "startTime": "2026-06-01 10:00:00",
  "endTime": "2026-06-01 10:10:00",
  "totalStock": 100,
  "perUserLimit": 1
}
```

### 缓存预热

`POST /api/admin/seckill/activities/{activityId}/preheat`

### 活动上线

`POST /api/admin/seckill/activities/{activityId}/online`

### 活动下线

`POST /api/admin/seckill/activities/{activityId}/offline`

## Agent 接口

### 创建 Agent 分析任务

`POST /api/admin/agent/tasks`

请求：

```json
{
  "taskType": "ACTIVITY_PRECHECK",
  "activityId": 10001
}
```

响应：

```json
{
  "taskNo": "AT202605290001",
  "status": "PROCESSING"
}
```

### 查询 Agent 任务结果

`GET /api/admin/agent/tasks/{taskNo}`

响应：

```json
{
  "taskNo": "AT202605290001",
  "taskType": "ACTIVITY_PRECHECK",
  "status": "SUCCESS",
  "outputText": "活动库存已预热，限流规则已启用，预计风险较低。"
}
```

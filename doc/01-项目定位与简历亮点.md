# 项目定位与简历亮点

## 项目定位

`FlashSaleX` 是一个 Java 后端秒杀系统，模拟电商平台在大促场景下的限时抢购业务。系统支持商品秒杀活动配置、活动缓存预热、用户抢购、Redis 原子库存扣减、消息队列异步创建订单、支付超时取消、后台运营管理、风控限流和 AI Agent 辅助运营分析。

项目适合作为 Java 后端求职简历项目，重点展示你对高并发场景、缓存、消息队列、数据库事务、接口安全和系统设计的理解。

## 适合面试展示的能力

- Spring Boot 项目工程化能力
- MySQL 表结构设计和索引优化能力
- Redis 缓存设计、Lua 原子操作和库存预扣能力
- 消息队列异步削峰能力
- 幂等、防重复提交、防超卖设计能力
- 分布式锁、限流、热点数据处理能力
- 接口鉴权、风控、黑名单能力
- Docker Compose 本地部署能力
- 可观测性和问题排查能力
- AI Agent 与传统业务系统结合的设计能力

## 简历写法示例

```text
FlashSaleX 秒杀系统

基于 Spring Boot 3 + MySQL + Redis + RabbitMQ 实现的高并发秒杀系统，支持活动配置、缓存预热、秒杀抢购、异步下单、库存扣减、订单超时关闭和后台运营管理。项目使用 Redis + Lua 实现库存原子预扣和一人一单校验，通过 MQ 异步削峰创建订单，并结合 JWT 鉴权、接口限流、幂等 Token 和风控黑名单提升系统稳定性。设计了 AI Agent 运营助手，用于活动风险巡检、库存预警、异常订单分析和压测报告总结。
```

## 面试亮点

1. 不是直接访问数据库扣库存，而是通过 Redis 预扣库存，降低数据库压力。
2. 使用 Lua 脚本保证库存扣减和用户购买记录写入的原子性。
3. 抢购成功后只发送下单消息到 MQ，订单由消费者异步创建。
4. 数据库层通过唯一索引兜底防止同一用户重复下单。
5. 使用延迟队列或定时任务处理订单超时关闭和库存回补。
6. 通过限流、验证码、黑名单和接口隐藏降低恶意请求风险。
7. 引入 Agent 模块，辅助运营人员做活动检查、风险分析和异常解释。

## 项目边界

第一版不做真实支付、不接真实短信、不做复杂推荐系统。支付使用模拟支付接口，短信验证码可以使用本地日志或控制台输出代替。

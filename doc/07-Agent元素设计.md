# Agent 元素设计

## Agent 在项目中的定位

Agent 不是替代秒杀主链路，而是作为运营和运维辅助模块存在。秒杀链路必须稳定、确定、可回滚；Agent 更适合做分析、总结、巡检和建议。

推荐定位：

```text
秒杀系统负责交易闭环
Agent 系统负责辅助决策
```

## Agent 模块架构

```text
管理端页面
   |
   v
Agent Task API
   |
   v
Agent Orchestrator
   |
   +--> Activity Tool：读取活动配置
   +--> Stock Tool：读取库存和库存流水
   +--> Order Tool：读取订单统计
   +--> Risk Tool：读取限流、黑名单、异常请求
   +--> Log Tool：读取错误日志和 MQ 失败记录
   |
   v
LLM 分析与总结
   |
   v
Agent 任务结果
```

## Agent 能力 1：活动上线前巡检

任务类型：`ACTIVITY_PRECHECK`

输入：

- 活动 ID
- 商品信息
- 活动时间
- 库存配置
- 限流规则
- 缓存预热状态
- MQ 连接状态

输出示例：

```text
活动可以上线，但有 2 个风险点：
1. 当前活动库存为 10000，但用户级限流未配置，可能导致单用户高频请求。
2. 活动缓存已预热，但验证码开关未开启，建议对热门活动开启验证码。
```

判断规则：

- 活动时间是否合法
- 商品是否上架
- 秒杀价是否低于原价
- Redis 库存是否和 MySQL 库存一致
- MQ 是否可用
- 限流是否开启
- 是否启用验证码

## Agent 能力 2：库存风险分析

任务类型：`STOCK_RISK_ANALYSIS`

输入：

- 活动 ID
- Redis 库存
- MySQL 库存
- 订单数
- 库存流水

输出：

- 当前库存是否一致
- 是否存在订单成功但库存未扣减
- 是否存在库存回补失败
- 是否需要人工处理

## Agent 能力 3：异常订单分析

任务类型：`ABNORMAL_ORDER_ANALYSIS`

分析对象：

- 重复下单失败记录
- MQ 消费失败记录
- 支付超时订单
- 取消后未回补库存订单
- 同 IP 高频请求

输出：

- 异常类型
- 影响范围
- 建议处理方式

## Agent 能力 4：压测报告总结

任务类型：`LOAD_TEST_SUMMARY`

输入：

- QPS
- 平均响应时间
- P95
- P99
- 成功率
- 错误率
- Redis CPU
- MySQL CPU
- MQ 堆积量

输出示例：

```text
本次压测峰值 QPS 为 3500，P95 响应时间 82ms，接口成功率 99.2%。
主要瓶颈出现在 MQ 消费端，活动开始后 30 秒内消息堆积达到 12000。
建议增加消费者实例数，并将订单创建批量写入策略作为下一步优化方向。
```

## Agent 能力 5：运营问答

任务类型：`OPS_QA`

示例问题：

- 这个活动为什么成功率下降了？
- 哪些用户请求异常？
- 当前库存和订单数量是否一致？
- 今天秒杀失败最多的原因是什么？
- 哪些接口最慢？

## Agent 不应该做什么

- 不直接扣库存
- 不直接创建订单
- 不绕过风控规则
- 不自动修改核心交易数据
- 不在没有人工确认的情况下执行补偿

## Agent 工具设计

### ActivityTool

职责：

- 查询活动详情
- 查询活动状态
- 查询缓存预热状态

### StockTool

职责：

- 查询 Redis 库存
- 查询 MySQL 库存
- 查询库存流水
- 计算库存差异

### OrderTool

职责：

- 查询订单数量
- 查询订单状态分布
- 查询异常订单

### RiskTool

职责：

- 查询限流记录
- 查询黑名单
- 查询异常 IP

### LogTool

职责：

- 查询错误日志
- 查询 MQ 失败记录
- 查询慢接口

## Agent 数据安全

- Agent 只能读取脱敏数据。
- Agent 结果需要记录任务日志。
- 高风险建议必须人工确认。
- Agent 输出不能直接作为交易结果。
- 所有 Agent 调用需要管理员权限。

## 面试表达

可以这样说：

```text
我在系统里加入了 Agent 模块，但没有把它放在核心交易链路里，因为秒杀链路要求确定性和强约束。Agent 主要用于活动上线前巡检、库存差异分析、异常订单解释和压测报告总结。它通过工具函数读取活动、库存、订单和风控数据，再输出分析建议，最后由管理员决定是否处理。
```

# 功能清单

## 用户端功能

- 用户注册
- 用户登录
- JWT 鉴权
- 查看秒杀商品列表
- 查看秒杀商品详情
- 获取秒杀接口动态地址
- 获取抢购验证码
- 发起秒杀请求
- 查询秒杀结果
- 查看订单列表
- 查看订单详情
- 模拟支付订单
- 取消未支付订单

## 管理端功能

- 管理员登录
- 商品管理
- 秒杀活动管理
- 秒杀库存配置
- 活动上下线
- 活动缓存预热
- 活动数据看板
- 订单管理
- 用户黑名单管理
- 风控规则管理

## 秒杀核心功能

- 活动开始前缓存预热
- Redis 维护秒杀库存
- Redis 维护用户秒杀成功标记
- Lua 脚本完成库存扣减和一人一单校验
- MQ 异步创建订单
- 消费者幂等处理
- MySQL 唯一索引兜底防重复下单
- 订单超时关闭
- 超时未支付库存回补
- 秒杀结果轮询查询

## 风控与安全功能

- JWT 登录鉴权
- 接口级限流
- 用户级限流
- IP 级限流
- 秒杀接口地址动态化
- 图形验证码或算术验证码
- 请求参数签名
- 黑名单拦截
- 重复提交拦截
- 幂等 Token

## 可观测性功能

- 请求日志
- 慢接口日志
- MQ 消费失败日志
- 库存同步异常日志
- 秒杀成功率统计
- 接口 QPS 统计
- 活动库存变化监控
- 下单链路 TraceId

## AI Agent 功能

- 活动上线前巡检 Agent
- 库存风险分析 Agent
- 异常订单分析 Agent
- 压测报告总结 Agent
- 运营问答 Agent
- 故障排查建议 Agent

## 第一版优先级

P0 必做：

- 登录鉴权
- 商品和活动管理
- 缓存预热
- 秒杀请求
- Redis Lua 扣库存
- MQ 异步下单
- 订单查询
- 防重复下单

P1 建议做：

- 接口限流
- 验证码
- 订单超时取消
- 库存回补
- Docker Compose
- Swagger 文档

P2 加分项：

- Agent 模块
- 可观测性看板
- 压测脚本
- 风控规则配置
- 多级缓存
